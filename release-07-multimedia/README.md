# Disclosure Files — Release 07 multimedia package

A publication-ready companion package for the eight-document Release 07 set. Built as a new directory; no customer ticket files were changed.

## Editorial guardrails
- **Verified record** means the supplied release inventory/document description says the item exists; it does not mean the underlying event is proven.
- **Interpretation** is a reasonable reading of context, provenance, or wording.
- **Speculation** is clearly marked and is not presented as fact.
- The four visual files are **RECREATIONS**, not photographs or scans.

## Contents
- `release-07-story.html` — responsive, self-contained story page with inline timeline, evidence legend, and four visual panels.
- `release-07-script.md` — concise narration/script for a 5–7 minute video or audio piece.
- `release-07-storyboard.md` — shot-by-shot production plan and captions.
- `assets/*.svg` — original vector recreation plates, each visibly watermarked RECREATION.
